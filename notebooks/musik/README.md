
# MUSiK Simulation Workspace

This folder hosts the notebooks and scripts that drive ultrasound simulations for the CIRS Model 073 breast phantom, using: [MUSiK](https://github.com/norway99/MUSiK) (Chan et al., IEEE TBME 2026).

MUSiK lives outside this folder as an embedded git repo at `guided_breast_biopsy/external/MUSiK/`, a clone of the personal fork [Morook97/MUSiK](https://github.com/Morook97/MUSiK).

The original upstream [norway99/MUSiK](https://github.com/norway99/MUSiK) is registered as `upstream` for future syncs.
